The Network Effect: Why Bigger Gets Better

A network's value doesn't grow with its users — it grows with the connections between them, which increase roughly with the square of the user count (Metcalfe's Law): 2 users support 1 possible link, but 6 users support 15.

It's the same reason a shared plant utility — a steam header, a flare system, a site-wide historian — gets more valuable every time another unit ties into it: each new tie-in multiplies the exchanges the network can support, not just adds one more user.

네트워크 효과: 커질수록 더 좋아지는 이유

네트워크의 가치는 사용자 수가 아니라 사용자들 사이의 "연결" 수에 비례해서 커집니다. 이 연결 수는 사용자 수의 제곱에 가깝게 늘어나는데(메트칼프의 법칙), 사용자가 2명이면 가능한 연결은 1개뿐이지만 6명이 되면 15개로 늘어납니다.

플랜트의 공용 유틸리티 — 스팀 헤더, 플레어 시스템, 사이트 전체 히스토리안 — 가 새 유닛이 하나 연결될 때마다 더 가치있어지는 것도 같은 이유입니다. 새로운 연결 하나가 사용자 한 명을 더하는 게 아니라, 그 네트워크가 지원할 수 있는 교환의 수를 배로 늘리기 때문입니다.
